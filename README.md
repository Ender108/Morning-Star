# Description
Morning Star is a modlist that enhances Skyrim's gameplay and visuals without losing the original's feel.

# Features
- Simon Magus' series of vanilla plus gameplay overhauls
- Visual overhaul using Open Shaders and PBR textures
- Rebalancing and integration of Fishing, Rare Curious, Saints & Seducers, and Survival Mode
- Various tweaks to vanilla quests and encounters

# Requirements
- Skyrim Special Edition (Steam version 1.7.104)
- Does NOT require nor use the paid Creation Club content

# Installation
1. Ensure [Visual C++ x64﻿](https://www.techpowerup.com/download/visual-c-redistributable-runtime-package-all-in-one/) is installed. If not, download it from the link, extract the archive, and run install_all.bat as admin. Restart your PC afterwards.
2. Ensure you have a clean, unmodified copy of Skyrim Special Edition. It must installed outside of your Program Files folders (e.g. "C:\Steam\steamapps\common\Skyrim Special Edition")
3. Download and install [Wabbajack](https://www.wabbajack.org/) anywhere outside of your Programs Files folders (e.g. "C:\Wabbajack"). Run Wabbajack.exe.
4. Click Settings in the bottom left, then click Log in next to Nexus Mods. Proceed to log in and authorize.
5. Click Browse lists, make sure Non-featured is checked, and then search Morning Star. Click on the box and then click Download & Install.
6. Set the Installation Location and Download Location anywhere outside of your Programs Files folders and outside your Wabbajack installation folder (e.g. "C:\Modlists\Morning Star" and "C:\Modlists\Morning Star\downloads").
7. Click Install in the bottom and wait until it says Finished installing Morning Star at the top. If any of the files fail to download, you will need to download them manually from their page and place it in the downloads folder.
8. Go to your Morning Star install folder and launch ModOrganizer.exe, Make sure SKSE is selected in the top left drop-down and click Run to play.
